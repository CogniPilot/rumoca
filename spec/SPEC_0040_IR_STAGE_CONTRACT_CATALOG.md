# SPEC_0040: IR Stage Contract Catalog

## Status
REFERENCE

## Summary

Lookup catalog of the per-stage Flat, DAE, Solve, and structural-lowering contract
rows referenced by [SPEC_0007](SPEC_0007_IR_PIPELINE.md).

## How To Use This Catalog

This annex holds no rules of its own. Every row below is a SPEC_0007 stage
contract and is **normative by reference from SPEC_0007**; the owning stage
section in SPEC_0007 states the governing requirement and links here. Cite rows
by their catalog ID (`DAE-C07`, `SOLVE-C13`, `STRUCT-T04`) so a reviewer can
find the exact obligation without loading the whole pipeline spec.

## Specification

### 0. Flat Stage Contract Catalog (SPEC_0007 Stage 2)

| ID | Rule | Where | Why |
|---|---|---|---|
| FLAT-C01 | Expandable-connector augmentation and false-conditional pruning complete before each typed Instance connection and virtual-connection-graph directive is consumed by one build-local topology plan and one atomic final projection. The topology plan completes before stream expressions are inserted; the projection jointly constructs roles, signs, connection sets, stream mixing, overconstrained selections, `equalityConstraint` calls, equations, assertions, connected domains, and provenance. Any unknown, malformed, partially active, or unsupported input fails before Flat mutation. | Instance-to-Flat connection lowering | Partial generation is wrong code; stream/root operators require complete topology. |
| FLAT-C02 | A record formal, actual, result, assignment, and call remains one nominally typed aggregate through Flat and DAE. | FLAT-C03 | A non-array component of effective record type selects its `equalityConstraint` from that exact checked record occurrence. Construction proves exactly two non-array inputs of that effective record type and one exact rank-one `Real[n]` output, retaining the selected function and output declaration identities. Unresolved or ambiguous association is rejected before connection lowering; `Real[0]` is the only vacuous result. | Resolve, Instance construction, and Flat connection lowering | Name/default scans and fabricated widths select the wrong relation. |

| DAE-C17 | Under MLS §4.4 and §8.5, every event-generating occurrence in a runtime binding equation owns the same typed relation, scheduled-time event, or sample clock that the occurrence would own in an equation-section equality | DAE event analysis and the binding's B.1 owner | Binding syntax cannot erase an event boundary needed to refresh the equation; occurrence identity still prevents duplicate owners |
| DAE-C18 | The scalar dependency view of a function result is derived once as exact parameter-scalar/record-field projections and substituted into each call's actual arguments.
