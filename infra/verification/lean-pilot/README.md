### Commands

On x86-64 Linux, the optional development shell provisions the pinned translator
pair and Elan without building Rumoca or changing the ordinary Rust shell:

```text
nix develop .#lean-pilot
read -r lean_pilot_toolchain < infra/verification/lean-pilot/lean-toolchain
elan run --install "$lean_pilot_toolchain" lean --print-prefix
command -v aeneas
```

The printed Lean prefix contains its `bin` directory; the printed Aeneas path
shares its directory with Charon. Elan installs the named toolchain if needed
without selecting a global default. Nix remains optional: equivalent pinned
tools can be provisioned separately. From the repository root, substitute the
two executable directories in the canonical replay command:

```text
CARGO_BUILD_JOBS=4 RUST_TEST_THREADS=4 RAYON_NUM_THREADS=4 cargo xtask verify lean-pilot --aeneas-bin /path/to/aeneas/bin --lean-bin /path/to/lean/bin
```

Use `nix develop -c cargo ...` where needed for the ordinary Rust environment.
