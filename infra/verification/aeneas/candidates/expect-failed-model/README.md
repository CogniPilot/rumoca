## Invariant and first divergence

The DAE-shaped [Rust reducer](fixture.rs) preserves both the nominal specialized
Option types and the original branded ID/view bodies. A Some must return the
original value; a None must produce the existing library model's panic result.
We do not replace either specialized body by a name-only alias to Lean Option.

The predecessor [Never-call repair](../never-call-continuation/README.md)
retains the call and eliminates its impossible successful result. Its remaining
opaque callee is the nongeneric Rust `core::option::expect_failed(&str) -> !`.
Pinned Rust option.rs:966 matches Some/None; option.rs:2256 delegates this leaf
to panic_display. No generic Display implementation is modelled here.

The new CoreOption definition returns `Result.fail Error.panic`, exactly the
panic abstraction of existing Option.expect. It is a **trusted typed library
contract**, not a proof of Rust's panic machinery or arbitrary Never behavior.
Message formatting, panic hooks, I/O, allocation and unwinding are outside this
observation model. The ordinary and specialized success bodies remain generated
from Rust; no generated Lean function body is edited.
