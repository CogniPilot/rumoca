# Rumoca 0.10.3

Release preparation from main `d4918832b7406792277957b805b07dba4c412125`.
Changes since v0.10.2 (`276e82bd0fd48960ac201e782918d28bf19cf7ce`, October 4).

## Required release-candidate additions (not yet qualified)

- PR467: evaluate when-body assertions only on activation and preserve checked values after a failed function assertion; native assertion/coverage gates remain pending on this combined candidate.
- PR470 by Minhyun Cho (@mhcho1994): preserve component-array member equations and record container/field shapes. Original contributor commits and attribution retained; failed CI diagnostics and repaired-candidate acceptance remain open.

## Compiler and Modelica correctness

- Expand MSL package and event coverage, refine state-event location and sliding-mode handling, and preserve charted state names and exact stream endpoints.
- Preserve loop/array/record writes, parent indices, indexed algorithm targets, discrete Real last-assignment semantics and when-chain priority. Reject unsupported partial-derivative functions and incomplete compiled lowering instead of executing partial models.
- Keep compact tensor/structured loop families and guarded scratch definedness; improve Integer-to-Real conversion, loop bounds, nested captures and conditional ownership.
- Evaluate buffered relations during simultaneous initialization. Preserve array when ownership, certified event coordinates and hard-stop interpolation bounds.

## FMI and code generation

- Extend FMI 2/3 C-profile support for input/time event relations, discrete equations, when clauses, sample events, enumeration types and typed function reductions.
- Improve FMI binding classification, compact function folds, checked tensor operations and internal sample-event WASM execution. Expose algebraic refresh and named ODE slots.
- Parameter-guarded exports retain derived-parameter refresh and validation paths. The underlying calculatedParameter spelling and set-at-initialization parameter/state-start propagation were already present in 0.10.2 (September 26 commit4e99c440); they are not a new post-0.10.2 fix. Later binding/initialization changes are included here, but dependent-parameter FMU regeneration remains subject to separate downstream validation. These notes do not claim that witness passed.
- Preserve Real array element types in GALEC projections, external tables and checked Solve views; improve WASM compiled-model APIs and compiler exports.

## Runtime, simulation and performance

- Add native trajectory sensitivities, adjoint objective gradients, A/B/C/D linearization and a SimulationSession stdio interface.
- Improve state selection, affine block solves, native typed regions, tensor fusion, contiguous event transfers and per-event copy cost. Settle switched affine blocks once per mode and reduce scalar arithmetic allocations.
- Restore the default Cranelift register allocator for native kernels; use the single-pass allocator only for the selected small-function path. Do not carry forward reverted broad allocator performance claims.
- Add the CanyonRun reinforcement-learning example. A successfully trained canyon controller is not established by source inclusion; its training, held-out and viewer acceptance remain separate work.
- Improve checked native/WASM image and SLAM algorithm execution, storage ownership and runtime loop kernels; no blanket physical or application qualification is inferred.

## Python, browser and editor

- Repair Python packaging and x86_64 macOS builds on Apple Silicon through Rosetta; the wheel matrix covers Linux x86_64/aarch64, macOS x86_64/arm64 and Windows x64 using the CPython3.10+ stable ABI.
- Add a playground assistant for Modelica/configuration/diagnostics and improve live-session backend decline reporting and periodic clock announcements.
- `compile --emit ast-json` now emits the input file's parser AST before name resolution. It does not require referenced libraries or `--model`; consumers expecting the resolved class tree must adapt.
- Preserve short-class descriptions/annotations and external-function annotations through parsing and cache decoding.

## Verification, CI and maintenance

- Improve MSL quality comparisons on common measured models, reviewed reference boundaries, phasor-angle comparison and exception accounting; report simulated/verified/excepted/unclassified counts explicitly.
- Repair main CI/setup handling, recover package-manager timeouts, preserve build provenance and formalization/specification catalogs, and document regenerable build-output cleanup paths.
- Existing release workflow gates publication on the tag's own CI jobs; GitHub Pages is deployed earlier after the WASM build and tag detection, before the final publication gate.
