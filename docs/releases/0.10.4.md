# Rumoca 0.10.4

Changes since [v0.10.3](https://github.com/CogniPilot/rumoca/releases/tag/v0.10.3) (`bc93cff7f7a4cccb5da5c84f8d72965885ff70c6`), through main `5fbb21c8b4df68cae5455bb7703da04890459bbe`. The published tag identifies the final release commit.

## Diagnostics and compiler correctness

- Unsupported external function implementations now report a source-feature diagnostic, EL001, instead of an invalid Solve IR contract, EL005. Direct and nested calls retain their function, symbol and call-site information. This fixes #489; it does not add an external-code loader (#497).
- Preserve nested `each` and `final` modifier prefixes through inheritance, and preserve the selected `inner` instance's actual arguments in nested replaceable function calls (#475, #491).
- Orient Boolean, Integer, String and enumeration connections from public outside inputs through the existing discrete connection graph (#479).
- Keep relations between external inputs and time in continuous root search, so a held input can still trigger a time crossing (#485).
- Load transitive source-root dependencies, including cyclic library references, without requiring users to list each dependency directly in their model (#494, #495).
- Rebuild structural memo results when their conditional-arm scope is invisible at the use site, retaining lazy branch construction (#504).
- Plan array comprehensions inside `when` equations, `when` statements and other model owners; unsupported dependent domains report a typed refusal instead of panicking (#507).
- Apply a constraining clause's modifiers to the replaceable declaration itself, not only to its redeclarations, in both the component and the short class form (MLS 7.3.2). A declaration's own modifiers still win, a `final` constraining modifier cannot be modified again, and a long-form replaceable class with constraining-clause modifiers and no single base is refused instead of dropping them. An extends modifier that states attributes and a binding, such as `extends Gain(k(min = 0) = 5)`, is now applied instead of being dropped (#551).
- `fill(s, n, ...)` accepts a record element, so `Item items[3] = fill(Item(), 3)` is no longer refused with ED020. A function's record-array output or local whose record has defaults starts each element at those defaults (#555).

## Simulation and preparation

- Add the opt-in `--solver velimplicit` fixed-step, linearly implicit Euler Model Exchange solver. Native builds with the `solver-velimplicit` feature use a 1 ms step and Jacobian reuse of 200 by default. Builds without that feature report the mode as unsupported. It is not the default solver (#496).
- Add the stdio session command `{"command":"values","names":[...]}`. The reply returns values in request order from one state observation, with `null` for unknown variable names. Protocol version remains 1; clients using older binaries must handle an EX011 unsupported-command reply (#505).
- Reuse certified shared work in causal Jacobian products and improve mixed derivative execution and dependency precision (#484, #499).
- Share the immutable pure-call table across portable WASM target-value families, and declare native Cranelift helper imports only for bodies which can call them (#500, #501).
- Copy `reinit` values at the end of the event-iteration step. A reinit was treated as an equation in the state it reinitializes, so `reinit(v, 2*v)` solved `v = 2*v` and gave `v = 0` (#486, #509).
- Hold a discrete variable defined by an ordinary equation, such as `Integer i = if time >= 0 then 3 else 1`, at its definition during initialization instead of its declaration seed (#511).
- In a live session with no stop time and no output schedule, `advance_to` results no longer depend on how often a client polls: a yield inside a step is served from the step's continuous extension instead of ending the step. Native components keep the previous behaviour, where every yield is a step boundary (#516).
- Recheck derived assignments after the certified algebraic projection of an event, repeating only when those values or relation memory change, in simulation and in generated FMI C (#545).
- Fix seed-dependent results in colored projection Jacobians: a fold or conditional region that reads the seed is no longer evaluated once and reused for every color (#527). Preserve scalar coordinates for assigned-state presence calls (#526), and subtract cross-product tangent terms in source order in native code, as the evaluator does (#540).
- Bound the work of pure-call dependency derivation, and compose each call's dependency relations once per call, so large estimator models no longer exhaust memory or spend minutes in solve lowering; the bounded analysis only adds dependencies (#520, #550).
- Reduce preparation and Jacobian work without changing computed values: run a seed schedule's directional programs in one native call, batch whole-block residual and Jacobian row calls, settle the initial view once per block Jacobian, prune state seed sweeps by exact assignment leaf dependencies, keep compact dual tensor rows in native registers, check refreshed values through a contiguous slice, share pure-call symbol lookup across native modules, and compile native functions in parallel when their module is finalized (#515, #521, #524, #538, #529, #530, #548, #553).
- WASM: share one private scratch buffer across an expression's programs, and emit private programs into shared modules with construction-sized register memory, so a large multibody model no longer exhausts wasm32 memory before its first step (#531, #539).

## Code generation

- Emit supported JAX Map/AffineStencil families as vectorized operations, retaining the checked scalar fallback for unsupported cases (#481).
- Keep large `sum()` reductions bounded in depth while preserving their ordered evaluation, avoiding the reported flatten-time crash (#482).
- Preserve passive offsets in composed GALEC matrix contractions and derive finite packed-index bounds from checked source functions. Unsupported integer-divisor cases remain refused (#502, #503).
- FMI export now provides exact directional derivatives (FMI 2 and FMI 3) and FMI 3 adjoint derivatives, built from the checked model rather than by finite differences. Capability attributes are emitted only for supported derivative profiles (#544).
- A generated Co-Simulation FMU retries a substep whose trial stage is non-finite, such as `sqrt` of a value the trial step drove below zero, instead of failing the communication step (#498, #512).
- GALEC: accept fixed-size slice assignments such as `y[4:6] := v + {1,2,3}` (#510); keep the sign of zero when negating a Real expression (#518); collect `pre()` reads in equation-section definitions and publish them at the settled event (#517); lower a runtime index into a one-element axis to that element (#528); and prove a packed index by the size parameter every call site passes (#542).
- The `embedded-c-galec` target now prints its C from a checked Solve algorithm block instead of a second code generator, and Solve C folds single-use Real expressions and names conditional pass-throughs (#533, #549).
- Generated C declares every scalar local it reads with a zero initializer, which avoids compiler "maybe uninitialized" warnings and undefined reads (#519).

## Packaging and build infrastructure

- Fix optional public client configuration during Pages staging (#474).
- Bind new MSL runtime snapshots to their retained model evidence before promotion (#546).
- Add a CI comparison of native humanoid performance with MuJoCo: an informational speed report and the existing task fidelity gate (#554).
- Enable main-push CI to publish the Rumoca package and dependency-build paths, with their closures, to the CogniPilot Nix cache when a write token is configured. Pull requests only read the cache. Downstream flakes must use matching pinned inputs to reuse those paths; this does not replace the published binary, Python or browser distributions (#508).

## Known issues

- The `embedded-c-galec` target refuses the RDD2 `ReducedRateController` with EL007 (a read of a possibly unassigned local). That model exported before #533 moved C printing onto the checked Solve algorithm block. A fix is planned for 0.10.5.
